# electroAD-tealca
Techno-economic analysis and life-cycle assessment model for an integrated organic wet-waste biorefinery producing aviation fuel blend stock, esters, fertilizers, and recovered salts.
electroAD-tealca
Techno-Economic Analysis and Life-Cycle Assessment Model for Integrated Organic Wet-Waste Valorization

This repository contains the techno-economic analysis (TEA), life-cycle assessment (LCA), process modeling assumptions, and supporting calculations associated with the manuscript:

Converting Organic Wet-Waste to Hydrocarbons, Esters, and Fertilizers: Process Design and Assessment

Authors:
Smith W. Pittman et al.

Overview

This repository supports the reproducibility and transparency of a systems-level process design for the conversion of organic wet waste into renewable fuels, chemical feedstocks, fertilizers, and recovered salts.

The modeled biorefinery integrates:

Electrochemically enhanced anaerobic digestion (ECE-AD)
Microbial chain elongation (CE)
Bipolar membrane electrodialysis (BMED)
Cheese whey homolactic acid fermentation
Continuous ammonia removal and salt recovery
Liquid-liquid extraction
Supercritical CO₂ extraction
Ketonization
Hydrodeoxygenation
Esterification and purification
Techno-economic analysis (TEA)
Life-cycle assessment (LCA)

The process converts manure, municipal food waste, cheese whey, and high-salinity water into:

Hydrocarbon mixtures suitable for Jet-A blendstock
Purified fatty acid esters
Ammonium sulfate
Magnesium sulfate
Sodium sulfate
Desalinated water
Repository Purpose

The purpose of this repository is to provide:

TEA and LCA model transparency
Supporting calculation files
Costing assumptions
Life-cycle inventory values
Process mass balance calculations
Figures and supplementary analysis
Reproducibility resources for the manuscript

This repository is not intended to function as a polished industrial software package. Instead, it serves as an academic and engineering research repository that documents the assumptions, calculations, and methodologies used throughout the study.

Process Description

The proposed process framework integrates biological, electrochemical, and thermochemical operations into a circular biorefinery platform.

Major Process Sections
1. Electrochemically Enhanced Anaerobic Digestion (ECE-AD)

Organic wet waste consisting primarily of manure and municipal food waste undergoes anaerobic digestion with electrochemical enhancement to increase volatile fatty acid (VFA) production and reduce methanogenesis.

2. Chain Elongation

VFAs are upgraded through reverse β-oxidation using lactate as a carbon donor to produce longer-chain carboxylic acids.

3. Seawater Bipolar Membrane Electrodialysis (BMED)

Seawater BMED generates:

HCl
NaOH
Sodium sulfate
Desalinated water

These streams are internally recycled throughout the process to reduce operating expenses and improve process circularity.

4. Cheese Whey Fermentation

Cheese whey is hydrolyzed and fermented to produce lactate for microbial chain elongation.

5. Fuel Production Pathway (Path A)

Recovered VFAs undergo:

Liquid-liquid extraction
Ketonization
Hydrodeoxygenation
Distillation

to produce a hydrocarbon mixture suitable for Jet-A blending.

6. Ester Production Pathway (Path B)

Alcohol conversion and esterification are used to produce purified fatty acid esters, including pentyl caproate and related compounds.
